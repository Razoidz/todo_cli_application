# To-Do CLI Application

A simple interactive command-line app for managing tasks. Tasks can be added,
viewed, completed, edited, deleted, and filtered by status.

## Requirements

- Python 3.12 or newer

## Run

From this directory, run:

```bash
python3 main.py
```

Choose an option from the menu and follow the prompts. Select **Save & Exit**
to save your tasks to `todo_cli_application.json` in the current directory.
If that file does not exist, the app starts with an empty task list.

## Task data

`todo_cli_application.json` stores task data locally and is intentionally
excluded from version control.
